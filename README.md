# Los Dioses del Ritmo — Sitio web oficial

Proyecto web estático para presentar la identidad artística, música, videos, trayectoria, enlaces oficiales, galería, shows, tienda y contacto de **Los Dioses del Ritmo**.

## Descripción

Este sitio reúne el universo visual y musical de la agrupación, destacando el **ritmo exótico del Chocó**, la identidad cultural del Pacífico colombiano y la propuesta digital del proyecto.

La página está construida con HTML y CSS, sin frameworks, y utiliza recursos visuales propios del proyecto junto con integraciones externas como YouTube, Spotify y plataformas musicales.

## Páginas del proyecto

- `index.html`: página de inicio con presentación del proyecto, promoción del álbum **Suena Bien**, reproductor de YouTube y sección destacada de Spotify.
- `enlaces.html`: página de enlaces oficiales hacia Beacons y Pacífico Master Beat.
- `biografia.html`: biografía y trayectoria de la agrupación, con integrantes, historia, logros y enfoque cultural.
- `musica.html`: página musical con reproductor de Spotify y enlaces a plataformas como Spotify, Apple Music, YouTube, Deezer, TIDAL, SoundCloud, Pandora, Amazon Music, YouTube Music, KKBOX, iHeartRadio y Audiomack.
- `videos.html`: galería de videos oficiales integrados desde YouTube.
- `shows.html`: espacio para futuras fechas, presentaciones y eventos.
- `shop.html`: sección de tienda en estado **Próximamente**.
- `galeria.html`: archivo visual con fotografías promocionales del grupo.
- `contacto.html`: formulario visual de contacto para mensajes, propuestas, eventos y colaboraciones.

## Tecnologías utilizadas

- HTML5
- CSS3
- Google Fonts
  - Bebas Neue
  - DM Sans
- Font Awesome, usado en la página de música para los íconos de plataformas
- Integraciones externas:
  - YouTube Embed
  - Spotify Embed
  - Enlaces a plataformas musicales

## Cómo ejecutar el proyecto

1. Descarga o clona el proyecto.
2. Mantén todos los archivos HTML en la raíz del proyecto.
3. Mantén el archivo `styles.css` en la raíz.
4. Guarda las imágenes dentro de `assets/img/`.
5. Abre `index.html` en el navegador.

También puedes usar la extensión **Live Server** en Visual Studio Code para visualizar los cambios en tiempo real.

## Recomendaciones para trabajar el proyecto

- Conserva los nombres de archivo que están enlazados en el código.
- Revisa que las imágenes existan dentro de `assets/img/`.
- No elimines `styles.css`, ya que todas las páginas dependen de ese archivo.
- Cuando agregues nuevas imágenes, optimízalas para web antes de subirlas.
- Usa textos `alt` descriptivos para mejorar accesibilidad.
- Si cambias una URL externa, actualízala en todas las páginas donde aparezca.
